# Car Body Type Classification — ResNet from Scratch

Классификация типа кузова автомобиля (Convertible, Coupe, Hatchback, Pick-Up, SUV, Sedan, VAN) на архитектуре ResNet, реализованной с нуля на PyTorch — без предобученных весов и без готовых реализаций из torchvision.models. На тестовом наборе Kaggle точность достигает 95–99% по всем классам; на случайных изображениях из интернета — 55–95% в зависимости от класса и условий съёмки, с приростом до 10–20% благодаря Test-Time Augmentation через серию кропов (Crop-TTA).

## Зачем этот проект

Задача была сознательно ограничена: реализовать архитектуру самостоятельно и обучить с нуля, без предобучения и без готовых блоков из библиотек — это совсем другой уровень сложности по сравнению с fine-tuning готового ResNet из torchvision. Перед реализацией был проведён сравнительный анализ десяти архитектур (VGG, AlexNet, MobileNet, EfficientNet, Inception, DenseNet, ShuffleNet, ViT, ConvNeXt, ResNet) по критериям сложности ручной реализации, зависимости от pretraining и требований к данным и ресурсам — ResNet выбран как лучший компромисс между простотой residual-блоков и устойчивостью обучения на глубоких сетях без предобучения.

Основная сложность оказалась не в архитектуре, а в разрыве между чистым датасетом и реальными фотографиями: модель, обученная на аккуратно обрезанных студийных снимках, плохо переносится на фото из интернета с разными ракурсами, масштабом и освещением. Большая часть работы ушла именно на то, чтобы закрыть этот разрыв — через аугментации и предобработку, а не через усложнение сети.

## Архитектура

Собственная реализация `ResNetCustom`: начальный свёрточный блок (Conv + BatchNorm + ReLU + MaxPool), последовательность Residual-блоков, глобальный average pooling, Dropout и финальный полносвязный классификатор на 7 классов.

```
Conv2d + BatchNorm + ReLU + MaxPool2d
  → ResidualBlock × N (Conv → BN → ReLU → Conv → BN → skip-connection → ReLU)
  → AdaptiveAvgPool2d(1×1)
  → Dropout
  → Linear → логиты по 7 классам
```

Skip-connections в Residual-блоках — ключевая причина, по которой ResNet выбран из десяти рассмотренных архитектур: они снижают проблему затухающего градиента на глубоких сетях и делают обучение с нуля (без предобучения) значительно более стабильным по сравнению с чисто последовательными архитектурами вроде VGG.

## Данные

[Cars Body Type Cropped](https://www.kaggle.com/datasets/ademboukhris/cars-body-type-cropped) — 7 классов кузовов, изображения обрезаны так, что автомобиль занимает большую часть кадра. Стандартное разделение train/valid/test из разметки датасета.

Предобработка на обучении: масштабирование до 512×512, нормализация, набор аугментаций (случайные повороты, цветовые искажения, горизонтальное отражение, `RandomResizedCrop`). Разрешение 512×512 подобрано экспериментально — на 128×128 модель теряла мелкие детали кузова и заметно чаще путала классы.

## Почему не просто "углубить архитектуру"

Первым интуитивным способом улучшить качество казалось усложнение сети: увеличение числа Residual-блоков с 4 до 6, удаление MaxPool, уменьшение stride в ранних слоях, расширение числа каналов. На практике это привело к моделям, требующим 20–45 ГБ RAM и до 66 часов на эпоху — при этом качество не улучшалось, а иногда становилось хуже. Отдельно был опробован приём с толстым padding вокруг изображения (в расчёте, что это снизит зависимость от масштаба автомобиля в кадре) — эксперимент провалился: распределение train/test разошлось, а модель на реальных фото стала работать хуже, чем без padding.

В обоих случаях "больше вычислений" не означало "лучше результат" — рабочим решением оказалось не усложнение модели, а изменение того, что именно ей показывают на входе.

## Crop-TTA — решение, которое реально сработало

Модель оказалась крайне чувствительна к масштабу автомобиля в кадре: датасет состоит в основном из крупных, хорошо освещённых фото, снятых с небольшого расстояния, тогда как на реальных снимках машина часто занимает меньшую часть кадра.

Решение — Test-Time Augmentation через серию кропов: изображение обрезается несколько раз с постепенно сужающимися границами, для каждого кропа модель делает независимое предсказание, итоговый результат — усреднение вероятностей по всем кропам. Это ослабляет зависимость от масштаба и делает предсказание устойчивее к тому, насколько крупно автомобиль присутствует в кадре.

```
Фото → серия кропов (от полного кадра к более узкому)
     → предобработка каждого кропа (Resize, ColorJitter, RandomAdjustSharpness, Normalize)
     → предсказание модели по каждому кропу
     → усреднение вероятностей по всем кропам
     → итоговый класс + таблица вероятностей
```

Именно Crop-TTA дал наибольший прирост качества среди всех опробованных подходов — на "шумных" интернет-фото усиление доходило до 10–20 процентных пунктов.

## Результаты

**Метрики обучения**: train loss стабильно снижается на протяжении обучения, финальное значение около 0.35; train accuracy выросла с ~20% до ~87–88%, validation accuracy — с ~18% до ~85%. Близость кривых train и validation указывает на отсутствие сильного переобучения.

**Точность по классам на тестовом наборе Kaggle** — 95–99% по всем 7 классам.

**Точность на случайных изображениях из интернета** заметно ниже и сильно зависит от класса и условий съёмки:

| Класс | Kaggle test | Интернет-фото |
|---|---|---|
| Convertible | ~95–99% | ~80–90% |
| Coupe | ~95–99% | ~55–70% |
| Hatchback | ~95–99% | ~80–85% |
| Pick-Up | ~95–99% | ~85–95% |
| SUV | ~95–99% | ~80–90% |
| Sedan | ~95–99% | ~55–70% |
| VAN | ~95–99% | ~85–95% |

Sedan и Coupe оказались самой сложной парой — визуально похожи, особенно на боковых ракурсах, и путаются заметно чаще остальных классов даже у более тяжёлых моделей на схожих задачах.

**Влияние условий съёмки**: крупный центрированный кадр — самый надёжный случай (~75–85% на интернет-фото); мелкий автомобиль на заднем плане, сильные блики и необычные ракурсы (сверху, сзади под углом) заметно снижают точность, вплоть до 60–70%. Применение Crop-TTA даёт +1–3% на чистом Kaggle-тесте и +10–20% на сложных интернет-изображениях — именно там, где TTA нужнее всего.

## Известные ограничения модели

- Sedan и Coupe стабильно путаются между собой из-за визуального сходства кузова.
- Модель чувствительна к масштабу автомобиля в кадре — Crop-TTA смягчает, но не убирает эту зависимость полностью.
- Есть смещение в сторону марок, чаще встречающихся в датасете — менее представленные марки распознаются хуже.
- Сильные блики и отражения на кузове иногда интерпретируются моделью как отсутствие крыши, что приводит к ошибочной классификации как Convertible.

## Содержимое репозитория

| Файл | Описание |
|---|---|
| `cars_body_type_classification_training.py` | Архитектура ResNetCustom (ResidualBlock, `_make_layer`), цикл обучения и валидации, сохранение лучшей модели |
| `cars_body_type_classification_test.py` | Инференс: генерация Crop-TTA кропов, предобработка, усреднение предсказаний, визуализация и таблица вероятностей |
| `prime_test.py` | Дополнительные тестовые сценарии / проверка на отдельных изображениях |
| `best_resnet_model_actual.pth` | Веса лучшей обученной модели |

## Запуск

```bash
pip install torch torchvision pillow numpy matplotlib tabulate requests

python cars_body_type_classification_training.py   # обучение модели с нуля
python cars_body_type_classification_test.py        # инференс с Crop-TTA на своём изображении
```

Для инференса на собственном изображении понадобятся загруженные веса `best_resnet_model_actual.pth`, полученные после обучения либо взятые из репозитория напрямую.
